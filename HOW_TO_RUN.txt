Bike workshop — send this folder to a teammate
==============================================

What you got
  A planar MuJoCo bicycle: small hills on mostly flat ground, a cascade
  balancer, and keyboard driving in the Simulate window.

Windows (PowerShell)
  1. Install Python 3.12+ from python.org (tick "Add python.exe to PATH").
  2. Unzip, then:

     cd workshop\mujoco_balance
     py -3 -m venv .venv
     .venv\Scripts\activate
     pip install -r requirements.txt
     python run_balance.py
     python run_balance.py --model new_bike

  Click the MuJoCo window, then (planar bike) — arrows only:
     Right  faster     Left  slower
     Up     shove      Space reset

  For --model new_bike (free-drive mesh bike, no cascade balancer):
     Up/Down  rear torque     Left/Right  steer     0 stop     Space reset

  (WASD is reserved by MuJoCo Simulate for visibility toggles.)

macOS / Linux
  unzip, then from this folder:
     ./run_balance.sh
     ./run_balance.sh --model new_bike
     ./run_balance.sh --model new_bike --debug

  On Ubuntu, install xdotool so the MuJoCo window auto-focuses
  (otherwise click it before using arrow keys):
     sudo apt install xdotool

Do not send the .venv folder. It is machine-specific; they recreate it
with the commands above.

Hills are brown mounds with a yellow pin (planar bike only). Overlay
"Nearest hill" says how far ahead. --controller none turns the balancer
off. --model new_bike loads the mesh bike (free-drive arrows).
--debug prints timing / key diagnostics and warns if realtime lags.
